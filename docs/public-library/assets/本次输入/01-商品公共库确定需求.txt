连锁店总部：商品公共库与模板同步 PRD

1. 项目概述

1.1 背景与目标

现有总部通过商品名称识别门店商品，同步时删除旧商品再创建新商品，造成商品身份变化、销售统计连续性受损。新增商品公共库维护统一商品资料、分配稳定公共 ID；模板从公共库选择商品；所有同步按公共 ID 处理，日常使用【更新商品信息】修改已关联商品，不再删除重建。

1.2 范围与角色







项目



本期范围





总部



独立商品公共库；表格导入、门店快捷导入、手动创建；模板选择公共库商品；单门店页面及操作不调整，连锁店和品牌店总部调整





门店



仅作为总部同步目标，接收商品公共ID，更新商品信息；保留本地经营数据；





用户端

账号权限



沿用商品、模板、同步、门店范围权限；提交、执行和重试再次校验

普通连锁逐门店选择；品牌账号沿用现有区域选店。

1.3 名词与商品身份







名称



说明





商品公共库



同一连锁内共用的总部商品资料库，不跨连锁共享





商品公共 ID



系统生成、只读、稳定、不可复用；同一公共商品在多个模板及门店使用同一公共 ID





门店商品 ID



门店本地商品记录身份；各店可以不同。更新信息及本版建议的同 ID 替换均保留它





第三方商品 ID



外部系统商品编码；可导入，不是公共 ID；不得用来跨店匹配





模板



公共商品的选品集合；建议使用引用，模板不形成可独立改名改价的新副本





执行项



一家门店 × 一个公共商品 × 一种操作，为结果及重试的最小单位





门店初始化



批量删除门店无商品公共ID的商品

示例：公共商品 GG10001 在 A 店本地 ID 为 501、B 店为 806。改名后同步仍找 GG10001，不能找名字相同的另一件商品。

同一门店同一公共 ID 最多一条有效商品；异常重复必须报错，禁止任选一条或同时更新多条。

2. 业务流程

总部商品公共库
  ├─ 表格导入
  ├─ 关联门店快捷导入
  └─ 手动创建
          ↓
  保存商品并生成/保留商品公共 ID
          ↓
模板管理 → 添加商品 → 搜索、复选公共商品 → 加入模板（公共 ID 不变）
          ↓
选择商品 / 同步所有商品 → 选择有权限的门店 → 选择四种操作之一
          ├─ 更新目标缺公共 ID：预检提示，显式转入独立初始化；不按名称认领、不自动改操作
          │    
          └─ 已建立关系：按门店 + 公共 ID 执行
                    ↓
          预览范围与操作后果 → 确认 → 生成任务及资料快照
                    ↓
          商品任务记录 → 门店结果 → 商品明细 / 失败列表
                    ↓
          修正失败原因 → 只重新执行失败项 → 保留历史尝试结果

3. 功能需求

3.1 菜单与页面分工

商品管理菜单顺序为：商品公共库 → 商品模板管理 → 商品任务记录 → 套餐任务记录。新增【商品公共库】菜单位于商品模板管理上方。







页面



职责





商品公共库



1、该栏目右侧操作区域展示的菜单依次为：商品管理、分类管理、属性管理、小料库管理、推荐标签；商品管理提供手动新建、表格导入、快捷导入商品功能；

2、该菜单属于新增的菜单入口，在左侧【商品模板管理】上方显示

3、该栏目包括：商品管理、分类管理、属性管理、推荐标签（同现有的商品模板的功能一样）、小料库管理（原【小料库管理】菜单移入该栏目）

4、该栏目复用现有的商品管理表格，新增商品的时候，需要新增【商品公共ID】字段；属性规则复用现有的，连锁店总部属性没有处理行化，需要在同步门店的时候处理属性行化





商品模板管理



维护模板及其引用商品；只提供添加、查看、移除、同步商品/同步所有商品





商品任务记录



展示四种同步及门店初始化结果，逐门店、逐商品追踪失败与重试

3.2 商品公共库列表--本次新增





默认栏目顶部常驻展示无公共 ID 商品说明（见 3.6.1 的完整文案），同时保留公共库导入说明，提供下载最新版导入模板链接。无公共 ID 说明在公共库各页签切换后仍可见，不因列表为空、搜索或分页而消失。



页签沿用商品管理、分类管理、属性管理、小料库管理、推荐标签。除了商品管理栏目需要调整优化，其他栏目复用现有的【商品模板库】栏目已有的功能；点击【商品公共库】菜单，默认页签是【商品管理】



复用了现有的商品表，所以商品属性值在连锁店总部是没有做行化处理的，同步到对应门店的时候才进行行化处理

3.2.1 商品管理页签





筛选：包含商品名称/公共ID、促销类型、商品分类；





商品名称：默认占位内容：请输入商品名称/公共ID；输入框支持商品名称模糊查询，公共ID精准查询



促销类型：默认全部，下拉值有：全部、无、折扣、第二份促销



商品分类：默认全部，下拉值有全部和全部未删除的一级分类



列表操作：包含【新建商品】【导入商品】【快捷导入商品】【批量修改分类】【批量删除】



列表字段：复选框、商品公共 ID、排序、商品名称、分类、分类类型、促销类型、价格、打包费、启用状态、操作。





商品名称：包括商品图片和商品名称，商品名称最多展示两行，超过...；商品信息右侧有编辑入口，可以编辑商品名称和商品图片



排序：可以在列表直接操作，鼠标焦点移除，保存成功



价格和打包费：可以在列表操作，鼠标焦点移除，保存成功



启用状态：列表仅展示，不可以操作



操作：编辑/复制/删除；



删除：①如果同步任务引用对应商品，不可删除，提示：商品正在同步，暂无法删除；②如果商品可以删除，模板引用的该商品会被同步删除，删除商品不影响门店。



复制：总库存、每日库存、虚拟销量三个字段去掉了，复制的时候也不需要复制这三个字段；复制保存为新公共商品，生成新公共 ID，不继承原商品公共 ID。



编辑：如果同步任务引用对应商品，不可编辑，提示：商品正在同步，暂无法编辑；



批量删除和批量修改分类：如果同步任务引用对应商品，不可删除，提示：商品正在同步，暂无法删除



无数据展示“暂无数据”；筛选无结果展示“暂无符合条件的商品”。启用状态右侧的问号文案：“仅启用的公共商品可同步到门店”

3.2.3 表格导入







规则



处理





表格字段



商品公共ID、商品名称、分类、价格、商品信息、商品描述、打包费、属性分类、属性；名称、价格必填，分类如果不填写，生成一个【默认】分类；打包费如果没有填写，导入时候默认为0





表格版本



使用当前最新版格式；旧格式不兼容时明确提示重新下载，不兼容旧表格





行数



最多 200 条数据，表头/示例行不算；超过即拒绝并说明数量





缺必填项



数据区某行缺必填时，表格整批导入失败





默认分类



分类空时创建或复用“默认”一级分类；只填名称、价格也可导入





属性分类缺失



不导入该行商品，错误提示：属性分类与属性配置必须同时填写；如果属性分类和属性均不存在，可以导入，这是一个普通商品





属性



填写的规则保持现有逻辑；如果小料属性在总部不存在，提示：第*行【商品名称】小料库缺少：小料名称、小料名称...





公共 ID



1、不必填，按文本读取，保留前导零；
2、未填写，导入后新建公共商品，系统生成新公共 ID
3、已填写，当前连锁公共库存在，更新该商品信息，保留公共 ID
4、已填写，当前连锁公共库不存在，该行失败，提示“第*行，商品公共 ID 不存在”；如果是多个商品公共ID不存在，每一行商品均需要提示出来，提示：“第*行、第*行...、第*行，商品公共 ID 不存在”；同时这些商品导入失败
5、同一文件出现重复的非空公共 ID 时应报错，提示：“第*行、第*行...、第*行的商品公共 ID 重复”，同时这些商品导入失败


导入之后需要展示成功多少商品，失败多少商品，以及失败原因

3.2.4 关联门店快捷导入





只能从当前连锁关联且账号有权限的门店导入，默认显示 10 家，支持搜索门店名称/ID。



选择一家门店，再按分类勾选商品；支持全选、单选、取消及已选列表；至少选择一件。



仅导入商品资料，不导入销量、赞、门店总库存、每日库存、虚拟销量。来源门店的旧商品不会因导入自动获得公共 ID。



门店中同名的不同商品按各自来源本地 ID 逐条处理；无公共 ID 的每条商品均新建公共商品，不以名称、分类合并。保留商品所属分类一级分类归属，如果商品存在二级分类，同步的时候对应商品调整到一级分类下；公共库缺少所需分类时随导入创建对应一级分类，不复制二级分类。

属性保留完整属性分类、属性组、属性值及其结构和选择规则，包括属性/规格/小料类型、单选/多选/必选、选择数量、规格组合、适用价格和小料配置等。



公共库缺少所需分类、属性时，需要将属性也同步到公共库的属性和分类管理里面；不能因总部尚无定义而丢弃属性、规格



如果导入总部公共库的时候商品的小料在总部没有，导入商品的小料类型调整为：规格。

快捷导入抽屉顶部说明文案：



按商品公共 ID 判断是否导入

① 门店商品有公共 ID，且公共库已有相同 ID：跳过，不重复导入、不覆盖。
② 门店商品有公共 ID，但公共库没有相同 ID：直接导入，保留原公共 ID。
③ 门店商品无公共 ID：直接导入，每件生成一个唯一的新公共 ID。
门店中同名的不同商品分别导入，不按名称或分类合并。商品分类和完整商品属性一并导入，包括属性组、属性值、规格及小料配置。
不导入门店销量、点赞、总库存、每日库存和虚拟销量。





如果是通过【快捷导入商品】导入到连锁店总部的商品：①如果总部没有对应的小料，不需要在总部创建小料，对应同步的商品小料属性类型默认为【规格】，属性管理里面会增加一条新的属性信息 ②如果导入商品的小料属性跟总部一致，对应的商品小料属性可以正常导入（总部的属性分类、属性名称均跟导入的商品一样的情况下，小料属性才可以正常导入显示）



说明：如果存在同步任务的时候，公共库商品信息、商品属性、商品分类、小料库均不可以编辑、删除；如果操作保存之后提示：商品正在同步，暂无法编辑/删除
