新增门店商品

下架门店商品
仅下架所选门店中商品公共 ID 相同的商品；未找到相同公共 ID 时不处理，不影响其他商品。

根据商品公共 ID 更新所选门店中相同ID商品的信息，保留原商品销售数据及默认不同步的经营配置；未建立关联时不新增、不清理旧商品，可显式转入独立初始化或单独新增。
