# App 全局截图监听与微信快捷分享功能需求

**需求类型：** 功能新增  
**适用平台：** Android  
**参考效果：** 淘宝截图后出现的左侧悬浮分享卡片（本需求仅保留“分享截图”按钮）

## 一、需求目的

用户在 App 内任意页面截图后，App 自动识别截图操作，重新生成当前页面或弹窗的图片，并在屏幕左侧显示一个小型分享卡片。用户点击“分享截图”，即可通过微信将图片发送给好友。

## 二、功能说明

### 1. 全局截图监听

- App 在前台时，用户在任意页面截图，均尝试自动检测（以系统支持的截图方式为准）。
- 页面切换后仍然有效，不需要用户手动开启。
- App 进入后台后，不进行截图检测和图片生成。
- 本期优先支持 Android 14 及以上系统。

### 2. 自动选择图片内容

| 截图时的界面 | 生成并分享的图片 |
|---|---|
| 普通页面 | 当前页面图片 |
| 页面内切换的子页面 | 当前完整页面图片 |
| 显示受支持的功能弹窗 | 仅弹窗图片 |
| 显示受支持的底部弹窗 | 仅底部弹窗图片 |

**核心规则：有受支持的弹窗时优先生成弹窗图片，否则生成当前页面图片。**

图片由 App 重新生成，不读取用户相册中的原始截图，因此与系统截图可能存在细微差异。系统状态栏、系统弹窗以及部分特殊弹窗不在本期保证范围内。

### 3. 截图分享悬浮卡片

- **出现时机：** 检测到截图并成功生成图片后自动显示。
- **显示位置：** 屏幕左侧，参考淘宝截图分享卡片样式。
- **卡片内容：** 上方为生成图片的缩略图，下方仅保留一个 **“分享截图”** 按钮。
- **不显示：** “识别截图”、商品搜索及其他功能入口。
- **自动关闭：** 5 秒内未操作，卡片自动消失。
- **手动关闭：** 点击卡片外部可关闭，且不影响原页面正常操作。
- **连续截图：** 如卡片尚未关闭，再次截图时更新为最新图片，不重复叠加卡片。
- **页面切换：** 卡片关闭，不将上一页面图片误用于新页面。
- **展示要求：** 卡片尽量小巧，不遮挡页面主要操作区域；弹出时不改变当前页面内容。

### 4. 微信分享

- 点击 **“分享截图”** 后，调起微信图片分享流程。
- **分享范围：** 本期仅支持发送给微信好友，不增加朋友圈等其他渠道。
- 用户在微信中自行选择好友并确认发送；App 不自动发送。
- 用户取消分享或从微信返回 App 后，分享卡片关闭。
- 未安装微信、无法调起微信或分享失败时，给出简洁提示，不影响 App 使用。
- 不要求先将重新生成的图片保存到系统相册。

## 三、用户使用流程

**用户截图 → App 检测截图 → 判断当前显示的是页面还是弹窗 → 重新生成图片 → 左侧显示缩略图及“分享截图”按钮 → 用户点击 → 打开微信选择好友发送。**

### 场景一：普通页面

用户在订单详情页截图，左侧出现分享卡片；点击“分享截图”，向微信好友分享订单详情页图片。

### 场景二：功能弹窗

用户打开订单操作弹窗后截图，分享卡片展示弹窗缩略图；分享时仅发送弹窗图片，不包含底层订单详情页。

### 场景三：底部弹窗

用户打开底部操作菜单并截图，分享卡片展示底部弹窗图片；点击后可发送给微信好友。

## 四、注意事项

1. 本期优先支持 Android 14 及以上；并非所有系统截图方式都能被检测到。
2. 生成图片不是系统保存的原始截图，动态内容可能与用户截图瞬间略有不同。
3. 不读取用户相册，不自动上传图片，不自动发送给微信好友。
4. 仅处理本 App 的页面，不获取其他 App 的画面。
5. 不支持系统弹窗及部分特殊弹窗；涉及支付、密码等敏感页面时应禁止生成或分享敏感内容。
6. 截图分享卡片不能出现在本次重新生成的图片中。
7. 截图检测、图片生成及微信分享均不得影响 App 的正常使用。

## 五、验收标准

1. App 前台任意受支持的普通页面截图后，自动出现左侧分享卡片，缩略图正确。
2. 显示受支持的弹窗时截图，缩略图和分享图片均仅包含该弹窗。
3. 分享卡片只有 **“分享截图”** 一个操作按钮，没有“识别截图”。
4. 点击按钮后能进入微信好友图片分享流程，用户可自行选择好友发送。
5. 5 秒不操作自动关闭；点击卡片外部可关闭。
6. 连续截图时卡片更新为最新图片，不出现多个重叠卡片。
7. App 切换页面或进入后台后，不出现旧图片误分享的问题。
8. 用户取消分享、未安装微信或分享失败时，App 不闪退、不卡顿。
9. 图片不会被自动保存到相册或上传服务器。

## 六、本期不包含

- Android 13 及以下版本的完整截图监听兼容。
- 截图内容识别、商品搜索、OCR 文字识别。
- 微信朋友圈、其他社交平台分享。
- 读取相册原始截图、跨 App 截图。
- 将弹窗和底层页面合成为一张图片。

## 七、最终效果

**App 内截图 → 左侧弹出“图片缩略图 + 分享截图”卡片 → 点击后分享到微信好友。**

有受支持的弹窗就分享弹窗图片；没有弹窗就分享当前页面图片。操作简单，参考淘宝的截图快捷分享体验。

## 八、设置项调整

1. **接单设置：** 移除「开启截图添加手机信息水印功能」开关及其说明。
2. **系统权限设置：** 移除「允许小镇外卖访问所有文件访问权限」设置项。
